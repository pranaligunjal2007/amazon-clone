Amazon Clone 🛒

A responsive Amazon-inspired e-commerce website built using HTML and CSS. This project recreates the visual structure of an online shopping platform, including a navigation bar, search section, hero banner, product/category cards, and footer.

Note: This project is created for educational and practice purposes. It is not affiliated with or endorsed by Amazon.

📌 Project Overview

The Amazon Clone project was developed to practice and demonstrate fundamental front-end web development skills, including HTML page structure, CSS styling, layouts, images, navigation elements, and responsive design concepts.

🚀 How to Run
Clone or download this repository.
Open the project folder in Visual Studio Code.
Open index.html.
Use Live Server in VS Code, or open index.html directly in a web browser.
The Amazon Clone homepage will open in your browser.
